# Bundled font software (OFL-1.1)

The demo uses these TTF files to measure text in Python. They are unmodified,
retain their original names and metadata, and are not used to style the page.
Each family includes Regular, Bold, Italic and BoldItalic faces, for 20 TTFs in
total. The fonts retain their own licenses alongside the project's MIT license.

| Family | Source | Included license |
| --- | --- | --- |
| Carlito | [Google Fonts, `ofl/carlito`](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/carlito) | `Carlito-OFL.txt` |
| Caladea | [Google Fonts, `ofl/caladea`](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/caladea) | `Caladea-OFL.txt` |
| Liberation Sans / Serif / Mono | [Official 2.1.5 release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5), [TTF archive](https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz) | `Liberation-OFL.txt`, `Liberation-AUTHORS.txt` |
