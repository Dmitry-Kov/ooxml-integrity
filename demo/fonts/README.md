# Bundled font software (OFL-1.1)

All TTF files are **unmodified** and retain their original names and metadata.
They are font-metric inputs to Python, not web fonts for the page's interface.
Each family has Regular, Bold, Italic and BoldItalic faces (20 TTFs in total).
The project's MIT license does not replace the fonts' own licenses.
