## Окна и особенности маршрута

- При каждом из двух открытий DOCX появились **по два** окна Visual Basic for Applications: `Run-time error '53': File not found: /Library/Application Support/Adobe/MACPDFM/MacPDFM.framework/Versions/A/MacPDFM`. Всего четыре окна. Каждое закрыто кнопкой End; надстройки и параметры безопасности не изменялись.
- Окна восстановления/починки DOCX и предупреждения о смене формата не появлялись.
- Комментарии классические: отдельной кнопки публикации и меню «…» нет. Ответ создан кнопкой Reply, разрешение выполнено командой Resolve.
- В доступных разделах Security и Privacy флажок Remove personal information from this file on save не отображался. В исходном и сохранённых settings.xml нет removePersonalInformation; авторы Reviewer A/B сохранены.
- Ввод длинных строк через typeText сначала пропускал символы. Поля имени исправлены через setValue и проверены до первого комментария. Тексты комментариев и замен вводились вставкой обычного текста через Word.
- Для большинства точных выделений использовалась доступность Word (selectText), в том числе для номера колонтитула и даты сноски. Для перемещения использован именно тройной клик и Cmd+X/Cmd+V.
- Ошибочная комбинация для New Comment открыла Paragraph; диалог закрыт Cancel. Один неточный двойной клик перед заменой thirty затронул заголовок; эта вставка немедленно отменена Cmd+Z, затем выполнена точная замена. В сохранённом пакете нет посторонней правки заголовка.
- Для визуальной проверки выбран Print Layout, масштаб 75%.

- `verification.json`: читаемость ZIP/XML, авторы и типы правок, тексты комментариев, связь ответа и resolved-состояние.
- `SHA256SUMS`: контрольные суммы исходника и двух результатов.

- Итоговая страница просмотрена в Word. Для обоих результатов дополнительно выполнен render_docx.py с bundled LibreOffice; получено по одной странице, обе PNG просмотрены. Рендеры находятся в qa-render-review-a и qa-render-word-review. Отображение правок и нумерации в LibreOffice отличается от Word; рендер не использовался для изменения файлов.
- Jev не вызывался: изменений кода нет; это детерминированная проверка захваченного состояния, а не модельное подтверждение поведения Office.
